# Amarena Pastelería Artesanal - Córdoba

Sitio web y catálogo interactivo de **Amarena Pastelería Artesanal** ubicada en Córdoba, Argentina.

## Características

- **Catálogo de Pastelería**: Presentación de especialidades, tartas artesanales, tortas personalizadas de cumpleaños y 15 años, pavlova con frutos rojos, marquise de chocolate y cajas de petit fours.
- **Modales Interactivos**: Detalle de variedades de tartas artesanales y delicias de la cocina artesanal.
- **Galería con Lightbox**: Visualizador en alta resolución con navegación accesible por teclado (Escape / Enter / Focus trap).
- **Formulario de Pedidos & WhatsApp**: Formulario de contacto con validación, feedback con confeti y enlace directo a WhatsApp para cotizaciones instantáneas.
- **Diseño Responsivo**: Adaptado para móviles y computadoras de escritorio, con barra de navegación contraíble y menú lateral accesible.
- **Optimización & SEO**: Metadatos OpenGraph, geolocalización de Córdoba Capital y Schema.org JSON-LD para Bakery.

## Tecnologías

- **React 18** + **TypeScript**
- **Vite**
- **Canvas-Confetti**
- Tipografías: *Beau Rivage*, *Playfair Display*, *Cormorant Garamond*, *Lora*

## Desarrollo

```bash
npm install
npm run dev
```

El servidor de desarrollo correrá en `http://0.0.0.0:3000`.
